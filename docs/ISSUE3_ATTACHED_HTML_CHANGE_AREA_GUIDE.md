
## Practical rule

Once `show_headed_validation_suites.ps1` has already narrowed the route to attached localhost HTML follow-up, prefer `show_google_issue3_top_level_attached_html_entrypoint.ps1` before reopening the longer issue `#3` quickstart or validation-chain notes again.

- generic attached localhost follow-up: go from `-ChangeArea attached-html` to the top-level attached page helper, then the attached-page shortcut, then the replay-route shortcut, then replay shortcuts, then the safe-route map
- Google-shaped attached page follow-up still matters: go from `-ChangeArea google-attached-html` to the top-level attached page helper, then the Google attached page entrypoint before narrowing further
- explicit bundle paths already pinned: stay on the bundle-first helper before widening back into the broader Google-only path
- saved summary or repo-root override already present: reopen the top-level attached page helper with that same context first, then choose replay shortcuts or the safe-route map only as needed

Only reopen the longer validation-chain notes after the route has already narrowed back into the wrapper-heavy safe path.
